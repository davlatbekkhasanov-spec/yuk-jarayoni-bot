# Deploy (Railway)

1. Repo: `davlatbekkhasanov-spec/yuk-jarayoni-bot`
2. **Start command:** `python bot.py`
3. **Variables** (majburiy — aks holda crash yoki mas'ul ishlamaydi):

| O‘zgaruvchi | Qayerdan olish |
|-------------|----------------|
| `BOT_TOKEN` | @BotFather |
| `ADMIN_ID` | Botda shaxsiy `/start` — ko‘rsatiladi |
| `GROUP_ID` | Guruhda `/id` |

Misol: `ADMIN_ID=123456789` (faqat raqam, bo‘sh joy yo‘q)
4. **Volume:** `/app/yuk_bot.db` → `DB_PATH=yuk_bot.db`
5. Botni guruhga qo‘shing, admin qiling; guruhda `/id` → `GROUP_ID`
